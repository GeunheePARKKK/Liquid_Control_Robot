## 모터 설정 (CubeMars 툴에서 설정 완료)

같은 CAN 버스에 모터 2개가 물려 있다.

| 모터 | CAN ID | Master ID | 상태 |
|:---:|:---:|:---:|---|
| 1축 | `0x01` | `0x00` | 단독 구동 확인 완료 |
| 2축 | `0x02` | `0x01` | 2축 동시 구동 테스트 중 |

> Master ID는 모터가 피드백을 올릴 때 쓰는 식별자.
> 실제로 어떤 값으로 올라오는지는 `motor_test.ino` 로그의 `rxid` 로 확인할 것.

## motor_test.ino

두 모터에 **동일한 목표**를 보내 ±0.5 rad을 0.5초 주기로 왕복시킨다.
두 축이 같은 동작을 하는지, 피드백이 각각 정상적으로 올라오는지 확인하는 용도.

### CAN 프로토콜

| 항목 | 값 |
|---|---|
| 속도 | 1 Mbit/s |
| 핀 | TX = GPIO4, RX = GPIO5 |
| 종단저항 | 100Ω |
| 송신 ID | `0x100 \| CAN_ID` (위치/속도 모드) |
| 송신 데이터 | `[0:3]` 목표 위치 float LE / `[4:7]` 속도 제한 float LE |

**유니버설 명령** — `0xFF` × 7 + 명령 바이트

| 바이트 | 동작 |
|:---:|---|
| `0xFB` | 에러 해제 |
| `0xFC` | enable |
| `0xFD` | disable |
| `0xFE` | 현재 위치를 영점으로 |

**수신 프레임**

| 바이트 | 내용 |
|---|---|
| `data[0]` | 상위 4bit = 에러 코드, **하위 4bit = 모터 CAN ID** |
| `data[1:2]` | 위치 (±12.5 rad) |
| `data[6]` | MOS 온도 |
| `data[7]` | 로터 온도 |

> 모터가 2대이므로 수신 프레임은 반드시 `data[0] & 0x0F` 로 어느 모터 것인지
> 구분해야 한다. 1축 시절 코드는 이 구분이 없어 2축에서는 값이 섞인다.

### 정상 동작 예시

```
모터 2개 초기화 완료 (CAN ID: 0x01, 0x02)
[모터1] rxid=0x000 상태=0 pos=+0.50rad temp=32/35
[모터2] rxid=0x001 상태=0 pos=+0.50rad temp=31/34
```

### 한쪽만 응답할 때

1. 종단저항 — 모터 2개면 버스 양 끝에 각각 필요할 수 있음
2. 2축 모터의 CAN ID가 CubeMars 툴에서 실제로 저장됐는지
3. CANH / CANL 분기 배선
