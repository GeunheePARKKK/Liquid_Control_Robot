## ESP32-S3 ↔ 우노 배선

| ESP32-S3 | | 우노 | 비고 |
|---|---|---|---|
| **GPIO17** (TX) | → | **S10** (D10) | 직결 (3.3 V 출력, 우노가 HIGH 로 읽음) |
| **GPIO18** (RX) | ← | **S11** (D11) | 선택. 우노 5 V 출력 → **1 kΩ + 2 kΩ 분압** 필수 |
| **GND** | — | **감압기 출력 (−)** | 우노 G 에 꽂지 말 것. 우노 GND 는 모터 전류가 지나는 길이라 바퀴 출발 때 ESP32 가 BROWNOUT 리셋됨 (2026-10-26 확인). 5 V 도 감압기 출력 (+) 에서 직접 |

## 우노 모터 배선 (2026-10-24 실물 확인)

MDD10A **한 장**의 두 채널로 앞바퀴 2개. 쉴드 S핀 번호 = 우노 D핀 번호.
`주행부_모터/README.md` 의 "우노 배선과의 대응" 표(D5/A0, D9/A2 …)와 **다르다**. 실물이 기준.

| 바퀴 | MDD10A | 쉴드 | 우노 핀 | 전진 DIR |
|---|---|---|---|---|
| 앞왼 (FL) | PWM2 / DIR2 | S6 / S4 | **D6 / D4** | LOW (`L_INVERT 1`) |
| 앞오른 (FR) | PWM1 / DIR1 | S9 / S8 | **D9 / D8** | HIGH (`R_INVERT 0`) |
| FL 엔코더 B상 | | S3 | D3 (인터럽트) | |
| FR 엔코더 B상 | | S7 | D7 (폴링) | |

예전 2WD 코드(FL D6/D4, FR D9/D8, 엔코더 B상만)와 동일. A상(D2, D5)은 불량이라 안 쓴다.

엔코더는 우노 안에서 50 ms 마다 두 바퀴 속도(cps)를 재어 **좌우 균형 보정**에 쓸 수 있다(`bal1`, 기본 끔). PWM 1 당 cps 가 좌우 같아지도록 trim(±35 % 한계)을 적분해 빠른 쪽을 줄이고 느린 쪽을 올린다. 명령 비율(직진 1:1, 회전 1:−1)은 유지. 우노 USB 에서 `?` 를 치면 `spd L R cps  bal on ±n%  motor L R` 로 보인다.

## 명령 (drive_monitor.py / ESP32 USB 시리얼 공용)

| 명령 | 동작 |
|---|---|
| `w` `a` `s` `d` | 전진 / 좌회전 / 후진 / 우회전. `x` 칠 때까지 계속 (시간 제한 없음). 처음엔 `vmin`(70) 으로 천천히, 같은 키를 또 칠 때마다 `vstep`(20) 씩 빨라져 `v`(255) 까지. 다른 키·정지 뒤엔 다시 `vmin` 부터 |
| `w1500` | 1.5초 전진 후 자동 정지 (a/s/d 도 같음). 실험 사이클용. 단계 올리기는 같음 |
| `x`, `stop`, 빈 줄 | 정지 (우노 감속 램프 `rampd` 로 서서히) |
| `!` | 비상 정지 (램프 없이 즉시) |
| `v<0~255>` | 최고 속도 (기본 255 = PWM 최대). 주행 중이면 현재 속도를 바로 이 값으로 |
| `vmin<0~255>` | 첫 단계 속도 (기본 70) |
| `vstep<1~255>` | 같은 키 한 번 더 칠 때 올라가는 양 (기본 20) |
| `hold<ms>` | `w` 만 쳤을 때 최대 주행 시간 (기본 0 = 무제한) |
| `ramp<ms>` | 우노 가속 램프 (기본 700, 0 = 즉시). 0→255 기준 |
| `rampd<ms>` | 우노 감속 램프 (기본 1500). 255→0 기준. `x` 를 쳐도 이 시간에 걸쳐 서서히 선다. `!` 은 즉시 |
| `e` | 우노 엔코더 카운트 0 |
| `trim<n>` | 고정 오조준 n % (−50~50). 양수 = 오른쪽 바퀴를 n % 줄임(왼쪽으로 휠 때), 음수 = 왼쪽 줄임, `trim0` 해제. 우노 EEPROM 에 저장되어 전원 꺼도 남음. 우노로 전달 |
| `bal0` / `bal1` | 우노 엔코더 좌우 균형 보정 끄기 / 켜기 (기본 끔. FR 엔코더 폴링이 펄스를 놓쳐 오히려 휘게 했음). 우노로 전달 |
| `?` | 상태(v·vmin·vstep·지금 속도) + 우노 마지막 보고 |
