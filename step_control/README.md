# step_control

스텝모터 제어 코드. **ESP32-S3 + DRV8825 + 바이폴라 스텝모터** 조합.

| 파일 | 내용 |
|---|---|
| [drv8825_s3_test.ino](drv8825_s3_test.ino) | DRV8825 **기본 동작 확인 테스트** (정/역회전 반복) |

> 상태: 무부하 회전 확인 완료. 발열 및 마이크로스텝 튜닝은 진행 중.

---

## 부품

| 항목 | 사양 |
|---|---|
| MCU | ESP32-S3 (3.3V 로직) |
| 드라이버 | DRV8825 캐리어 보드 |
| 모터 | 바이폴라 스텝모터 (4선), 1.8°/스텝 = 200스텝/회전 |
| 전원 | 18V (VMOT 허용 범위 8.2 ~ 45V) |
| 필수 부품 | **전해 커패시터 100µF / 35V 이상** |

## 배선

### 핀 연결

| DRV8825 핀 | 연결 | 비고 |
|---|---|---|
| VMOT | 18V (+) | 8.2 ~ 45V |
| GND *(VMOT 바로 아래)* | 18V (−) | |
| B2, B1 | 모터 코일 1 (2선) | |
| A1, A2 | 모터 코일 2 (2선) | |
| FAULT | 미연결 | |
| GND *(맨 아래)* | ESP32-S3 GND | 18V(−)와 **공통 필수** |
| ENABLE | 미연결 | LOW = 동작. 발열 저감 시 GPIO 연결 |
| M0 / M1 / M2 | 미연결 | 전부 LOW = 풀스텝 |
| **RESET** | ESP32-S3 **3V3** | **필수** |
| **SLEEP** | ESP32-S3 **3V3** | **필수** |
| STEP | GPIO 5 | |
| DIR | GPIO 4 | |

> **DRV8825에는 VDD(로직 전원) 핀이 없다.** A4988에서 VDD였던 자리가 FAULT 출력이다.
> 로직 전원 대신 **RESET과 SLEEP을 3V3에 직접 물려야** 드라이버가 동작한다.
> 이 두 핀은 내부 풀다운이 걸려 있어서, 미연결 상태면 드라이버가 리셋에 잠긴 채 아무 반응이 없다.

### 전원부 결선도

커패시터는 전원 라인에 **병렬**로 걸친다. 직렬로 넣으면 DC가 차단되어 전원이 아예 안 들어간다.

```
18V (+) ──────┬──────────────────► DRV8825  VMOT
              │
             [+] 긴 다리
        전해 커패시터 100µF / 35V 이상
             [−] 짧은 다리 (몸통 흰 띠 쪽)
              │
18V (−) ──────┴───┬──────────────► DRV8825  GND  (VMOT 바로 아래)
                  │
                  └──────────────► ESP32-S3 GND
```

- 커패시터는 **드라이버 VMOT/GND 핀에 최대한 가깝게** 배치할 것. 멀면 효과가 반감된다.
- 전원선은 짧게. 길면 LC 스파이크가 커진다.

### 모터 코일 짝 찾기

A/B 중 어느 쪽으로 가는지, 한 쌍 안에서의 순서는 **상관없다**(회전 방향만 바뀐다).
**같은 코일의 두 선을 갈라 꽂는 것만** 피하면 된다.

| 방법 | 판정 |
|---|---|
| 멀티미터 저항 모드 | 1~5Ω → 같은 코일 / OL → 다른 코일 |
| 멀티미터 없을 때 | 두 선 끝을 꼬아 붙이고 축을 돌려서 **뻑뻑해지면** 같은 코일 |

## 전류 제한(VREF) 설정

**반드시 모터를 연결하기 전에** 설정한다. 이걸 건너뛰면 모터와 드라이버가 탄다.

```
전류 제한(A) = VREF(V) × 2       →       VREF = 전류 ÷ 2
```

1. **모터 4선을 뺀 상태**로 VMOT에 전원 인가
2. 멀티미터 검은선 = DRV8825 GND, 빨간선 = 보드 위 가변저항 **금속 나사**
3. 드라이버로 천천히 돌려 원하는 값에 맞춘다
4. **전원 끄고** 모터 연결 → 다시 전원

| VREF | 전류 제한 | 용도 |
|---|---|---|
| 0.25V | 0.5A | 첫 동작 확인 (토크 약함, 안전) |
| 0.4 ~ 0.5V | 0.8 ~ 1.0A | 일반 운용 |
| 모터 정격 ÷ 2 | 정격 | 상한선. 넘기지 말 것 |

> 가변저항이 **최대로 돌아간 채 출하되는 보드가 많다.** 이 상태로 모터를 연결하면
> 전원이 감당 못 해 전압이 주저앉는다 (실제로 18V → 1.7V로 붕괴하는 현상을 겪음).
> 값이 안 움직이면 돌리는 방향이 반대다. 억지로 밀어붙이면 가변저항이 망가진다.

## 주의사항

| 항목 | 내용 |
|---|---|
| **모터 탈착** | **전원이 인가된 상태에서 모터선을 꽂거나 빼면 드라이버가 파괴된다.** 배선 변경 시 반드시 전원부터 차단 |
| **커패시터 극성** | 흰 띠 / `−` 표시 쪽(짧은 다리)이 GND. 거꾸로 꽂으면 쇼트되고 파열될 수 있음 |
| **커패시터 내압** | 18V 사용 시 **35V 이상**. 16V·25V짜리는 사용 금지 |
| **역극성** | DRV8825는 역극성 보호가 없다. VMOT/GND를 반대로 꽂으면 즉시 사망 |
| **최대 전압** | 45V 절대 초과 금지 |
| **측정 위치** | 드라이버 핀(2.54mm 간격)에 직접 프로브를 대면 인접 핀과 단락되기 쉽다. **브레드보드 레일에서 측정할 것** |
| **방열** | 방열판 필수. 발열은 전압이 아니라 **전류(VREF)** 가 좌우한다 |

## ESP32-S3 GPIO 선택

클래식 ESP32와 핀 배치가 완전히 다르다. 클래식 기준 예제를 그대로 옮기면 동작하지 않는다.

| 핀 | 사용 가부 |
|---|---|
| **26 ~ 32** | ❌ 내장 SPI 플래시 / PSRAM 전용 |
| **33 ~ 37** | ⚠️ 옥탈 PSRAM 모델(N8R8, N16R8)에서 사용 불가 |
| **0, 3, 45, 46** | ⚠️ 스트래핑 핀. 부팅에 영향 |
| **19, 20** | ⚠️ USB D− / D+ |
| **4, 5, 6, 7, 15, 16, 17, 18** | ✅ 안전 |

> ⚠️ **`gimbal_control`이 CAN TX/RX로 GPIO4 / GPIO5를 사용한다.**
> 짐벌과 스텝모터를 한 보드에 통합할 때는 STEP/DIR을 **GPIO 15 / 16** 등으로 옮길 것.

## drv8825_s3_test.ino

정회전 1바퀴 → 역회전 1바퀴 → 정회전 5바퀴를 반복한다. 시리얼 모니터 **115200 bps**.

| 상수 | 기본값 | 설명 |
|---|---|---|
| `STEP_PIN` / `DIR_PIN` | 5 / 4 | |
| `STEPS_PER_REV` | 200 | 1.8° 풀스텝 기준. 0.9° 모터면 400 |
| `pulseUs` | 1500 | 펄스 폭(µs). 클수록 느림 |

**속도 튜닝**: `pulseUs`를 1500 → 800 → 400으로 줄여가며 탈조가 나는 지점을 찾는다.
소리가 거칠어지거나 회전이 멈추는 지점이 한계.

**보드 설정**: Arduino IDE → `ESP32S3 Dev Module`.
업로드가 안 되면 BOOT 버튼을 누른 채 RESET을 눌렀다 떼고 재시도.

## 트러블슈팅

이 프로젝트에서 실제로 겪은 순서대로 정리.

| 증상 | 원인 | 조치 |
|---|---|---|
| 시리얼은 뜨는데 모터 무반응 | RESET/SLEEP 미연결 | 둘 다 3V3에 연결 |
| " | GND 미공통 | 18V(−) ↔ ESP32 GND 도통 확인 |
| " | VREF = 0V | 가변저항을 돌려 0.25V 이상으로 |
| **전원 전압이 붕괴** (18V → 1.7V) | **VREF 과다 + 전원 용량 부족** | **모터 뺀 채 VREF를 0.25V로 낮춤** ← 실제 원인 |
| 제자리에서 진동만 함 | 코일 짝 오배선 | A/B에 꽂힌 4선 중 가운데 둘을 교환 |
| 툭툭 끊기며 탈조 | 속도 과다 또는 토크 부족 | `pulseUs` 증가 또는 VREF 소폭 증가 |
| 역방향 회전 | — | 한 쌍 내 두 선 교환, 또는 코드에서 DIR 반전 |
| 드라이버 과열 | VREF 과다 / 정지 중 여자 상태 유지 | VREF 인하, ENABLE로 정지 중 차단, 송풍 |
| 프로브 접촉 시 스파크 | 100µF 충전 돌입전류 (정상) 또는 인접 핀 단락 | 레일에서 측정. 전원 전압이 유지되면 무해 |

### 진단 순서

문제가 생기면 이 순서로 좁히는 것이 가장 빠르다.

1. **홀딩 토크 테스트** — 전원 인가 상태에서 축을 손으로 돌린다.
   뻑뻑하면 코일에 전류가 흐르는 것(→ STEP 신호 문제),
   가볍게 돌면 전류가 안 나가는 것(→ 전원/VREF 문제).
2. **모터 분리 테스트** — 모터 4선만 빼고 VMOT 측정.
   전압이 정상 복귀하면 단락이 아니라 **전류 문제**로 확정.
3. **STEP 신호 확인** — 코드 실행 중 STEP 핀을 DC 전압으로 측정. 약 1.6V(3.3V의 절반)면 정상.

## 발열에 대해

DRV8825의 발열은 **전압이 아니라 전류**가 좌우한다. 18V든 24V든 VREF가 같으면 발열은 비슷하다.

| 온도 감각 | 대략 | 판정 |
|---|---|---|
| 1~2초 댈 수 있음 | 50~60°C | 정상 |
| 1초도 못 댐 | 70°C↑ | VREF 인하 권장 |
| 모터가 멈췄다 몇 초 뒤 재기동 | — | **열보호 작동. 반드시 조치** |

**저감 방법** (효과 순): VREF 인하 → 정지 중 ENABLE로 출력 차단 → 송풍 → 공급 전압 인하

> 스텝모터는 **정지 중에도 코일에 전류가 계속 흐른다.** 위치 유지가 필요 없는 구간에서는
> ENABLE을 HIGH로 올려 출력을 차단하면 발열이 크게 줄어든다. 단, 축을 잡아주는 힘도 사라진다.
