# 시리얼 명령 — 파라미터 기능

[`합력벡터_제어.ino`](합력벡터_제어.ino) 기준. 115200 baud.

값을 바꿔도 저장되지 않는다. 전원을 껐다 켜면 아래 기본값으로 돌아온다.

## 게인 — 얼마나 기울일지

| 명령 | 기본 | 기능 |
|---|---|---|
| **`g`** | 0.30 | **수평 게인.** 차체 기울기를 몇 %나 상쇄할지. `g1.0` = 완전 수평. `g0.3` = 30%만 상쇄(70%는 기운 채로) |
| **`ag`** | 0.00 | **합력 게인.** 가속할 때 계산된 각도만큼 눕힐지. `ag1.0` = 물리 계산값 그대로. `ag0` = 가속 무시, 수평제어만 |

이 둘이 **뭘 목표로 할지**를 정한다.

## 응답 — 얼마나 빨리 갈지

| 명령 | 기본 | 기능 |
|---|---|---|
| **`r`** | 30 °/s | **트레이 최고 속도.** 목표가 아무리 멀어도 이 속도까지만 |
| **`f`** | 0.15 | **최종 지령 부드럽게.** 올리면 반응 빠르고 거칠어짐. 내리면 매끈하고 느려짐 |
| **`ad`** | 0.20 | **가속 목표각만 부드럽게.** 가속도 신호가 원래 지저분해서 따로 거는 필터 |

`ad` 는 가속 항에만, `f` 는 수평+가속 다 합친 최종 지령에 걸린다.

이 셋이 **목표까지 어떻게 갈지**를 정한다.

## 모터 — 얼마나 세게 잡을지

| 명령 | 기본 | 기능 |
|---|---|---|
| **`kp`** | 1.0 | **강성.** 목표로 얼마나 세게 당길지. 올리면 정확히 따라가지만 진동 위험 |
| **`kd`** | 0.10 | **감쇠.** 빨리 움직이는 걸 얼마나 방해할지. 올리면 왕복이 줄지만 미세진동 늘어남 |

`act` 가 `cmd` 의 75~80% 밖에 안 가는 드룹은 `kp` 가 낮아서다.

## 방향·동작

| 명령 | 기능 |
|---|---|
| `dp` / `dr` | 안쪽축 / 바깥축 **회전 방향 뒤집기** (토글) |
| `arm` / `stop` | 모터 켜기 / 끄기 |
| `z` | **모터 영점 재설정** — 지금 트레이 자세를 0 으로 |
| `t` | 시험 구동 8초 (IMU 안 거치고 CAN 만 확인) |
| `d` | CAN 전송 주기. `d2` = 50Hz |
| `q` | 화면 출력 켜기/끄기 |
| `?` | 현재값 전부 보기 |

## 서로 얽히는 것들

| 증상 | 원인 |
|---|---|
| `ag` 를 올려도 안 먹는다 | **`r` 이 범인.** 목표는 커졌는데 갈 속도가 없다 |
| `kp` 를 올렸다 | **`r` 도 다시 봐야 한다.** 토크가 `Kp × 오차` 라 둘이 곱해진다 |
| 합력만 끄고 싶다 | `ag0`. `g` 와 독립이라 수평제어는 살아 있다 |

되돌릴 때 순서는 `ag0` → `g0.3` → `stop`.

## 명령 없는 값 (코드에만)

| 이름 | 기본 | 기능 |
|---|---|---|
| `DIR_ACC` | +1 | 합력 목표각 부호. 실측 확정 |
| `LIMIT_DEG` | 25° | 지령 각도 상한 |
| `ACC_REF_LIMIT` | 20° | 합력 목표각 자체의 상한 |
| `ACT_LIMIT_DEG` | 50° | 실제 위치가 넘으면 폭주로 보고 끈다 |
