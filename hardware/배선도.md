# 배선도 (ESP32-S3)

현재 배선 상태 정리. 연결 절차는 [모터_ESP32연결.md](모터_ESP32연결.md) 참고.

| 구분 | 상태 |
|---|---|
| 짐벌모터 ×2 (CAN) | 연결 완료 |
| IMU ×2 (SPI) | 핀 배정 확정 |
| 모터 드라이버 UART | 핀만 예약 (미사용) |

## 2. 전원

| 항목 | 값 |
|---|---|
| 공급 전압 | **24V** (모터 허용 8~32V) |
| 전류 제한 | 1~2A (테스트 시) |
| ESP32 / IMU / 트랜시버 | 3.3V |

## 3. CAN — 짐벌모터 ×2

모터 케이블: XT30(2+2) ↔ 4가닥

| 케이블 색 | 신호 | 연결 위치 |
|---|---|---|
| 🔴 빨강 | 전원 + | 전원공급기 + (24V) |
| ⚫ 검정 | 전원 − | 전원공급기 − (+ 공통 GND) |
| ⚪ 흰색 | CAN_H | 트랜시버 CANH |
| 🔵 파랑 | CAN_L | 트랜시버 CANL |

> 흰색/파랑이 바뀌면 통신만 안 되고 고장은 안 남. 빨강/검정 극성만 주의.

### 트랜시버 ↔ ESP32-S3

| 트랜시버 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| TXD | GPIO 4 |
| RXD | GPIO 5 |

### 종단저항

- CANH ↔ CANL 사이에 **100Ω**
- 모터 2개가 같은 버스에 붙으므로 **CAN ID를 서로 다르게** 설정해야 함

## 4. SPI — IMU ×2

보드 라벨이 I2C 표기(`SDA`/`SCL`/`SDO`)지만 SPI 4-wire 모드에서는 아래와 같이 동작.

| IMU 보드 라벨 | SPI 기능 | ESP32-S3 |
|---|---|---|
| **SDA** | MOSI | GPIO 11 |
| **SCL** | SCK | GPIO 12 |
| **SDO** | MISO | GPIO 13 |
| **CS** | Chip Select | 베이스 **9** / 트레이 **10** |
| VIN | 전원 | 3V3 |
| GND | 접지 | GND |

`SDA` / `SCL` / `SDO` 3개는 두 IMU가 **병렬 공유**, `CS`만 개별.

```
ESP32-S3                    베이스 IMU        트레이 IMU
─────────                   ──────────        ──────────
  3V3 ──────┬─────────────── VIN ──────┬──────── VIN
  GND ──────┼─────────────── GND ──────┼──────── GND
GPIO11 ─────┼─────────────── SDA ──────┼──────── SDA
GPIO12 ─────┼─────────────── SCL ──────┼──────── SCL
GPIO13 ─────┼─────────────── SDO ──────┼──────── SDO
GPIO 9 ─────┼─────────────── CS         │
GPIO10 ─────┼──────────────────────────┴──────── CS
            └── 10kΩ 풀업 ×2 → 3V3
```

### SPI 설정

| 항목 | 값 |
|---|---|
| 클럭 | 1 MHz |
| 모드 | SPI_MODE0 |
| 비트 순서 | MSBFIRST |

```cpp
SPI.begin(12, 13, 11);   // (SCK, MISO, MOSI)
```

### 트레이 IMU 케이블 (회전부)

트레이 IMU는 짐벌 위에서 회전하므로 일반 배선과 다르게 처리.

| 항목 | 사양 |
|---|---|
| 전선 | 연선(stranded) 실리콘, 28~30 AWG |
| 배선 경로 | 회전축에 최대한 가깝게 + 서비스 루프 |
| 차폐 | 실드는 ESP32 쪽 **한쪽만** 접지 |
| 직렬저항 | SCL·SDA에 33~100Ω |
| 디커플링 | IMU 옆 100nF + 케이블 끝단 10µF |
| 모터 전원선 | 같이 묶지 말고 물리적으로 분리 |

## 5. 공통 그라운드

아래 4곳을 반드시 한 점으로 묶는다.

```
전원공급기 (−)  ─┐
CAN 트랜시버 GND ─┤
ESP32-S3 GND     ─┼── 공통 GND
IMU ×2 GND       ─┘
```

IMU GND는 모터 전류가 흐르는 경로와 공유하지 않고 **전용선으로 ESP32까지 직결**.

## 6. ESP32-S3 사용 금지 핀

| GPIO | 이유 |
|---|---|
| 19, 20 | USB D− / D+ |
| 22 ~ 25 | S3에 존재하지 않음 |
| 26 ~ 32 | SPI 플래시 |
| 33 ~ 37 | 옥타 PSRAM 모듈(N8R8 등) |
| 0, 3, 45, 46 | 스트래핑 핀 |
| 43, 44 | UART0 (시리얼 모니터) |
| 38 | DevKit RGB LED |

**여유 핀:** 1, 2, 6, 7, 8, 14, 15, 16, 21, 47, 48

## 7. 배선 검증

전원 인가 후 순서대로 확인.

| 대상 | 확인 방법 | 정상 |
|---|---|---|
| 모터 보드 | 표시등 | 초록불(Enable) 점등 / 빨간불 미점멸 |
| IMU (LSM6DSOX) | `WHO_AM_I` = `0x0F \| 0x80` | `0x6C` |

IMU 응답 이상 시:

| 응답 | 의심 |
|---|---|
| `0xFF` | MISO 미연결 / CS가 안 내려감 |
| `0x00` | MISO 단선 / GND 미연결 |
