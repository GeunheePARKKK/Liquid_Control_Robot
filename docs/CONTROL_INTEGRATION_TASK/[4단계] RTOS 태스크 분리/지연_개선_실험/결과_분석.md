# 합력 직접보상 지연 실험 결과

## 결론

현재 자료가 직접 지지하는 결론은 다음과 같다.

- RTOS는 주 지연 원인이 아니다. 제어 틱 최대 약 0.63 ms, 10 ms 초과와 CAN 실패는 0이다.
- `MAX_RATE=120 deg/s` 슬루 클리핑은 대부분 0~1%라 주 지연 원인이 아니다.
- PITCH 모터 경로는 빠르고 추종률이 거의 1이다.
- ROLL은 Kd 조정 뒤에도 모터 경로가 느리고, 수동 입력 대역에서 명령보다 크게 움직인다.
- `CMD_LPF 0.15→0.30`은 안정성을 유지하며 필터 지연을 줄였다.
- `ACC_LPF 0.20→0.25`는 PITCH만 빨라지고 ROLL 떨림을 키워 채택하지 않았다.
- CAN 50→100 Hz는 두 축 `cmd→act`를 약 10~15 ms 줄였고 통신 오류는 없었다.
- 현재 실물 구성에서는 ZV를 끈 채 직접보상 경로를 먼저 다듬는다.

잠정 채택값:

```text
zv0, vf1, ad0.20, f0.30, r120, d1
kpp2.0, kdp0.13, kpr2.0, kdr0.40
```

## 1. ROLL Kd 조정

바깥축 `Kp=2.0`을 유지하고 `Kd`만 올렸다.

| 로그 | ROLL Kd | `cmd→act` | 추종률 | 떨림 | 입력 대역 |
|---|---:|---:|---:|---:|---:|
| `A_kpr2.txt` | 0.13 | 115 ms | 1.50 | 0.012° | 1.36 Hz |
| `B_kdr025.txt` | 0.25 | 100 ms | 1.33 | 0.015° | 1.44 Hz |
| `C_kdr040.txt` | 0.40 | 85 ms | 1.31 | 0.013° | 1.32 Hz |

`Kd` 증가는 ROLL의 오버슈트와 상호상관 지연을 줄였지만 `0.40` 부근에서 개선이
포화했다. Kd는 주로 감쇠를 조절하므로 계속 올리는 것으로 대역폭 부족을 해결할 수 없다.

## 2. 초기 필터 분해

`raw_*` 로그를 추가한 뒤 필터 구간과 모터 구간을 분리했다.

| 로그 | 설정 | ROLL `raw→act` | ROLL `cmd→act` | 추종률 | 떨림 |
|---|---|---:|---:|---:|---:|
| `G_base.txt` | `ad0.20 f0.15` | 185 ms | 90 ms | 1.27 | 0.014° |
| `H_f030.txt` | `ad0.35 f0.30` | 165 ms | 95 ms | 1.42 | 0.030° |
| `I_f025.txt` | `ad0.20 f0.25` | 170 ms | 90 ms | 1.34 | 0.014° |

`H_f030`은 두 필터를 동시에 완화해 지연은 줄었지만 3.85 Hz 제자리 진동이 관측됐다.
원인을 분리하기 위해 이후 시험부터 한 번에 하나의 값만 바꿨다.

## 3. 표준 baseline 반복성

설정:

```text
zv0, vf1, ad0.20, f0.25, r120, d2
kpp2.0, kdp0.13, kpr2.0, kdr0.40
```

60 BPM 메트로놈과 같은 동작 순서로 3회 반복했다.

| 축 | `cmd→act` | `raw→act` | 추종률 | 떨림 | 입력 대역 |
|---|---:|---:|---:|---:|---:|
| PITCH | 40 ms | 120~130 ms | 0.97~0.98 | 0.015~0.016° | 1.05~1.16 Hz |
| ROLL | 90~95 ms | 165~175 ms | 1.35~1.43 | 0.013~0.018° | 1.44~1.55 Hz |

ROLL 전체 지연은 평균 약 168 ms였고 반복 범위가 약 10 ms였다. 따라서 같은 입력
대역에서 10~15 ms보다 작은 차이는 명확한 개선으로 보지 않는다.

PITCH 드룹 80%가 한 로그에서만 나왔지만 다른 두 로그는 유효한 유지각이 없어 비교할
수 없었다. 동적 추종률과 상관은 정상이므로 이 한 값만으로 PITCH Kp를 올리지 않는다.

## 4. CMD 필터 `f0.25→f0.30`

`ad0.20`과 모터 게인은 고정했다.

| 축 | `f0.25` | `f0.30` | 판단 |
|---|---:|---:|---|
| PITCH `cmd→act` | 40 ms | 40~45 ms | 모터는 동일 |
| PITCH `raw→act` | 120~130 ms | 105~110 ms | 감소 경향 |
| ROLL `cmd→act` | 90~95 ms | 95~100 ms | 입력 대역 차이로 직접 비교 제한 |
| ROLL `raw→act` | 165~175 ms | 160 ms | 약 5~15 ms 감소 |
| ROLL 떨림 | 0.013~0.018° | 0.015~0.017° | 증가 없음 |

동일 파일 안의 `want→act − cmd→act` 차이로 본 CMD 필터 몫은 약 30 ms에서
20~25 ms로 줄었다. 정지 떨림이 증가하지 않아 `f0.30`을 잠정 채택했다.

두 `F030` ROLL 입력 대역이 1.17 Hz와 1.71 Hz로 달라 추종률 차이는 필터 효과로
해석하지 않는다.

## 5. ACC 필터 `ad0.20→ad0.25`

`f0.30`과 모터 게인을 고정했다.

| 축 | `ad0.20` | `ad0.25` | 판단 |
|---|---:|---:|---|
| PITCH `raw→act` | 105~110 ms | 90~95 ms | 15~20 ms 개선 |
| ROLL `raw→act` | 160 ms | 160 ms | 개선 없음 |
| ROLL 떨림 | 0.015~0.017° | 0.022~0.024° | 약 40% 증가 |

정지 구간의 짧은 FFT 참고값에서 `AD025_01`은 약 2.63 Hz, `AD025_02`는 약
3.68 Hz 성분이 상대적으로 커졌다. 짧은 수동 시험이라 공진 주파수로 확정할 수는
없지만, 병목인 ROLL 지연 이득 없이 노이즈만 증가했으므로 `ad0.25`를 기각하고
`ad0.20`을 유지했다. `ad0.30` 이상은 진행하지 않았다.

## 6. CAN 50→100 Hz

설정은 `ad0.20 f0.30`으로 고정하고 `d2→d1`만 바꿨다.

| 항목 | CAN 50 Hz | CAN 100 Hz |
|---|---:|---:|
| PITCH `cmd→act` | 40~45 ms | 30 ms |
| ROLL `cmd→act` | 95~100 ms | 85 ms |
| PITCH 전체 지연 | 105~110 ms | 100~105 ms |
| ROLL 전체 지연 | 160 ms | 155~160 ms |
| ROLL 떨림 | 0.015~0.017° | 0.022~0.024° |

두 CAN100 로그 모두 다음을 만족했다.

```text
TX실패 0
10ms초과 0
샘플드롭 0
이벤트드롭 0
명령드롭 0
최대 제어 틱 약 0.63 ms 이하
```

정지 ROLL에서 약 2.7~2.8 Hz 성분이 상대적으로 커졌지만 진폭은 약 0.02° 수준이다.
육안 진동이나 이상음이 없다면 10~15 ms의 일관된 `cmd→act` 개선을 취해 `d1`을
잠정 채택한다. 물을 올리는 시험에서는 이 성분이 수면을 자극하는지 다시 확인해야 한다.

## 7. 현재 병목과 다음 단계

현재 ROLL은 CAN100에서도 `cmd→act` 약 85 ms이고 추종률이 약 1.38~1.42다.
그러나 좌우 방향은 바퀴가 아니라 상자를 끄는 시험이라 다음 외란이 섞인다.

- 정지마찰과 stick-slip
- 상자 yaw 회전
- 바닥 충격과 프레임 비틀림
- IMU와 트레이 위치 차이에 따른 회전 가속도

ROLL이 PITCH보다 느린 현상은 반복됐지만 그 차이 전부를 바깥축 관성으로 단정하지
않는다. 같은 ROLL 입력 대역의 후보끼리 비교하고, 가능하면 좌우 저마찰 이동 조건을
만든 뒤 게인을 조정한다.

다음 후보는 `kpr2.5, kdr0.45`지만 실행 전 모터의 실제 전류·토크 한계를 확인해야 한다.
`kpr3.0` 이상은 현재의 불확실한 토크 추정만으로 시도하지 않는다.

## 8. ZV에 대한 현재 판단

현재 ZV를 끄는 이유는 단순히 지연을 각도로 환산했기 때문이 아니다.

- 사람이 만든 외란을 IMU가 사후 측정한 뒤 명령을 생성한다.
- ZV 2임펄스는 약 208 ms 전 목표와 현재 목표를 섞고 평균 약 102 ms를 추가한다.
- 액체 고유주파수 2.19 Hz는 계산값이고 실측하지 않았다.
- 실제 트레이 절대각과 액체 변위를 측정하지 않는다.
- 수동 입력은 반복 가능하지만 동일한 가속 궤적은 아니다.

따라서 현재 환경에서는 ZV를 구현할 수는 있어도 슬로싱 억제 효과를 신뢰성 있게
검증할 수 없다. 실물에서는 `zv0`으로 직접보상 경로를 먼저 완성하고, ZV는 반복 가능한
가속 입력 또는 선행 가속 명령과 액체 관측 수단이 확보된 뒤 별도로 평가한다.

## 9. 해석 한계

- `act`는 모터 엔코더이지 트레이 절대각이 아니다.
- `raw`는 펌웨어가 계산한 필터 전 목표각이지 별도 계측기의 물리 가속도가 아니다.
- 상호상관 지연은 입력 주파수에 따라 달라지며 순수 전달지연이 아니다.
- 로그가 약 33 Hz라 5 ms 탐색 격자는 보간 결과다. 실질 해상도는 약 ±15 ms다.
- USB CDC에서 약 0~1%의 줄 손상이 발생한다. 분석기는 필드 구성이 깨진 줄을 제외한다.
- `슬로싱 위상`은 계산 주기 456 ms를 사용한 참고값이며 액체 측정값이 아니다.
