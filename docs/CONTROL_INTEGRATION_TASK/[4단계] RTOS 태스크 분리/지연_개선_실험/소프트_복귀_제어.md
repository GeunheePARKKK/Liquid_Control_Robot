# 가속 종료 소프트 복귀 제어

## 목적

기존 직접보상은 현재 IMU 가속도로 합력 평형 목표각을 계산한다. 가속 중에는 트레이가
합력에 수직인 방향을 잘 따라가지만, 가속이 사라지면 목표각도 곧바로 0으로 수렴한다.
액체에는 이전 가속으로 생긴 운동이 남아 있으므로 트레이가 이 목표를 빠르게 따라
급정지하면 액체가 용기 벽면으로 치솟을 수 있다.

`soft_return_rtos.ino`는 합력 평형 목표각 공식이나 모터 게인을 바꾸지 않고, 가속 종료
구간에만 상태를 갖는 꼬리 파형을 추가한다.

```text
현재 가속도만 사용하는 직접보상
  theta_eq = F(a_now)

소프트 복귀
  theta_shaped = theta_eq + theta_tail(acceleration history)
```

이 코드는 아직 액체 실험으로 효과가 검증되지 않은 **실험 버전**이다. 펌웨어 컴파일과
정적 검증만 완료했다.

## 파일과 적용 범위

- 실험 코드: [`soft_return_rtos.ino`](soft_return_rtos.ino)
- 기준 코드: 상위 폴더의 `zv_shaping_rtos.ino`
- 제어 주기: 100 Hz
- 적용 위치: `ACC_LPF` 뒤, 최종 목표각 및 `CMD_LPF` 앞
- 적용 축: PITCH와 ROLL이 독립적으로 종료를 검출

신호 사슬은 다음과 같다.

```text
IMU
  → raw 합력 목표각
  → ACC_LPF
  → ref
  → ZV 또는 소프트 복귀
  → shaped  (로그 필드 이름은 zv_pitch/zv_roll 유지)
  → want = ACC_GAIN·shaped − GAIN·base_angle
  → CMD_LPF
  → slew
  → cmd
  → CAN/MIT 모터
  → act
```

ZV와 소프트 복귀를 겹치면 두 번 성형되어 의도하지 않은 지연과 파형이 생긴다. 따라서
`sr1`은 ZV를 자동으로 끄고, `zv1`은 소프트 복귀를 자동으로 끈다.

## 상태기

축마다 다음 상태를 따로 가진다.

| 상태 | 동작 |
|---|---|
| `DIRECT` | 기존 `ref`를 그대로 통과시키고 유효 가속을 감시한다 |
| 종료 확인 | 유효 가속을 한 번 본 뒤 `raw`가 종료 임계값 아래인지 확인한다 |
| `HOLD` | 종료 확인 순간의 `ref`를 그대로 유지한다 |
| `RETURN` | 유지각에서 0까지 최소저크 곡선으로 복귀한다 |
| `LEVEL` | 0에 가까워진 기존 `ref`를 다시 통과시킨다 |

새 가속이 활성 임계값을 넘으면 `HOLD` 또는 `RETURN`을 즉시 취소하고 `DIRECT`로
복귀한다. 전환 과정의 남은 계단은 기존 `CMD_LPF`와 `MAX_RATE`가 제한한다.

기본 `ACC_LPF=0.20`에서 원입력이 0이 된 뒤 30 ms가 지나면 필터값은 대략

```text
(1 - 0.20)^3 = 0.512
```

가 되어 직전 값의 약 51%가 남는다. 코드는 이때의 `ref`를 그대로 잡으므로 상태 진입
순간 새로운 각도 계단을 만들지 않는다.

## 최소저크 복귀

복귀 구간의 정규화 시간 `x`를 0에서 1까지 증가시키고 다음 곡선을 사용한다.

```text
s(x) = 10x^3 - 15x^4 + 6x^5
theta_out = theta_hold · (1 - s(x))
```

시작과 끝에서 위치 변화율과 가속도가 0이 되어 단순 선형 램프보다 급격한 시작·정지를
줄인다. 이 방식은 액체 위상을 정확히 상쇄하는 ZV가 아니라 트레이 복귀가 액체에 새로
전달하는 충격을 줄이는 궤적 제한기다.

## 명령과 기본값

기능은 부팅 시 꺼져 있다. 기존 동작과 비교할 수 있도록 모든 값은 시리얼 명령으로
바꿀 수 있다.

| 명령 | 기본값 | 허용 범위 | 의미 |
|---|---:|---:|---|
| `sr1` / `sr0` | OFF | 0 또는 1 | 소프트 복귀 켜기/끄기 |
| `sra1.5` | 1.50° | 0.2~10° | 실제 가속으로 인정할 `raw` 크기 |
| `sre0.75` | 0.75° | 0.05° 이상, `sra` 미만 | 종료 후보 임계값 |
| `srd30` | 30 ms | 10~200 ms | 종료 임계값이 지속되어야 하는 시간 |
| `srh100` | 100 ms | 10~500 ms | 종료 시 남은 목표각 유지시간 |
| `srr120` | 120 ms | 20~1000 ms | 최소저크 수평 복귀시간 |

`arm`, `disarm`, `sr0`, 파라미터 변경 때 상태를 초기화한다. 유지각 절댓값이 0.15°보다
작으면 의미 없는 미세 동작을 만들지 않고 `LEVEL`로 넘어간다.

## 빌드

Arduino IDE는 스케치 폴더와 `.ino` 이름이 같아야 한다. 독립적으로 빌드하려면
`soft_return_rtos` 폴더를 만들고 그 안에 `soft_return_rtos.ino`를 둔다.


## 첫 실험 명령

펌웨어 기본값을 믿지 않고 비교에 필요한 설정을 모두 보낸다.

```powershell
python capture.py --port COM8 `
  --cmd "zv0,sr1,sra1.5,sre0.75,srd30,srh100,srr120,vf1,ad0.20,f0.30,r120,d1,kpp2.0,kdp0.13,kpr2.0,kdr0.40,arm" `
  --pre 6 --post 26 --out SOFT_RETURN_01.txt
```

기존 비교 기준은 같은 조건에서 `sr0`으로 기록한다.


## 실험 절차

1. 빈 트레이 또는 적은 물로 낮은 속도에서 방향과 종료 동작을 먼저 확인한다.
2. 같은 수위, 같은 용기, 같은 방향에서 `sr0`과 `sr1`을 번갈아 기록한다.
3. 메트로놈 60 BPM과 같은 이동거리·정지시간을 유지한다.
4. 각 설정을 최소 3회 반복한다.
5. `raw`가 0 근처로 돌아간 시각과 액체가 첫 벽면 최고점에 도달한 시각을 영상과
   로그에서 맞춘다.
6. 이상 방향, 큰 2차 파동, 기구 충격이 생기면 즉시 24 V 전원을 차단한다.

## 로그 판정

기능이 정상적으로 발동하면 다음 순서가 보여야 한다.

```text
raw        종료 임계값 아래로 복귀
ref        ACC_LPF 때문에 계속 감쇠
zv_*       약 100ms 평탄 구간 뒤 120ms S-curve로 0 복귀
cmd/act    기존 필터와 모터 지연을 포함해 shaped 목표를 추종
```

`zv_pitch/zv_roll`이라는 필드명은 기존 분석 도구와 로그 호환성을 위해 유지했다. `sr1`
상태에서는 ZV 출력이 아니라 소프트 복귀가 적용된 최종 합력 목표각이다.

소프트 복귀의 성공 여부는 `cmd→act` 지연 감소만으로 판단하지 않는다. 다음을 함께 본다.

- 종료 직후 액체의 첫 벽면 상승 높이
- 반대편에 생기는 두 번째 파동 높이
- 수평으로 돌아오는 총 시간
- 의도하지 않은 재발동 횟수
- `cmd`와 `act`가 꼬리 파형을 실제로 재현하는지

## 튜닝 방향

한 번에 한 값만 바꾼다.

| 관찰 | 우선 조정 |
|---|---|
| 강하게 움직였는데 기능이 발동하지 않음 | `sra`를 조금 낮춘다 |
| 가속 도중 자주 HOLD로 잘못 진입 | `sre`를 낮추거나 `srd`를 늘린다 |
| 종료 직후 기존 방향의 벽면 상승이 여전히 큼 | `srh` 또는 `srr`을 20 ms씩 늘려본다 |
| 반대편에 더 큰 두 번째 파동이 생김 | `srh`를 줄이고 다음으로 `srr`을 줄인다 |
| 새 가속에 늦게 반응 | `sra`를 낮추되 정지 노이즈보다 충분히 크게 둔다 |

시간을 계속 늘리면 성능이 좋아지는 것은 아니다. 이 로직은 정확한 액체 위상 모델을
쓰지 않으므로 지나친 유지와 느린 복귀가 새로운 파동을 만들 수 있다.

## 한계

- 베이스 IMU 하나로 액면의 실제 위상과 진폭을 측정하지 않는다.
- 정밀한 ZV/ZVD나 액체 상태 피드백을 대체하지 않는다.
- 수위·용기·방향이 달라지면 최적 시간이 바뀔 수 있다.
- 수동 밀기 입력의 반복성이 낮으므로 영상과 최소 3회 반복이 필요하다.
- PITCH와 ROLL의 바닥 접촉 조건 및 기구 관성이 다르므로 축별 결과를 직접 비교하지
  않는다.

문제가 생기면 `sr0`으로 끄면 기존 직접보상 경로로 즉시 돌아간다.
