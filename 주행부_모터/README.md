# 주행부 ESP32-S3 배선

DC 모터 4개 + MDD10A 2개 + 엔코더 4개를 **별도의 ESP32-S3(2번 보드)** 한 장에 붙인다.
짐벌·수위센서·스텝모터는 지금까지 쓰던 1번 보드에 그대로 남는다.

작성 2026-09-06.

---

## 구성

| 보드 | 담당 | 핀 사용 |
|---|---|---|
| **1번 ESP32-S3** (기존) | 짐벌 CAN, 차체 IMU, 수위센서, **스텝모터 2개** | 1·2 수위 / 4·5 CAN / 11·12 I2C / 19·20 USB / 17·18 보드 간 UART / **14·15·16·21 스텝** |
| **2번 ESP32-S3** (신규) | **DC 모터 4개, MDD10A 2개, 엔코더 4개** | 아래 표 |

두 보드는 UART 한 줄로 잇는다. 2번 보드가 가감속 명령을 내는 순간 1번 보드에 알리면,
짐벌이 IMU로 가속을 재기 전에(65ms 앞서) 트레이를 먼저 기울일 수 있다.

### 엔코더 4개

| 엔코더 | A상 (보라) | B상 (파랑) | Vcc (갈색) | GND (녹색) |
|---|---|---|---|---|
| 왼쪽 앞 | **GPIO 8** | **GPIO 9** | 3V3 | GND |
| 왼쪽 뒤 | **GPIO 10** | **GPIO 11** | 3V3 | GND |
| 오른쪽 앞 | **GPIO 12** | **GPIO 13** | 3V3 | GND |
| 오른쪽 뒤 | **GPIO 14** | **GPIO 15** | 3V3 | GND |

A상·B상 모두 **PCNT(펄스카운터) 하드웨어**가 센다. 우노에서 쓰던 인터럽트 0/1 + PCINT 구분이
필요 없고, 4개 엔코더 전부 쿼드러처(방향 포함)로 CPU 부하 없이 읽힌다.

## 반드시 확인할 것

### 1. 엔코더 전압 — 5V를 넣으면 핀이 상한다

우노 쉴드에서는 엔코더 Vcc가 5V였고, 그러면 A/B 출력도 5V로 나온다.
**ESP32-S3 GPIO는 5V를 못 받는다.** 엔코더 갈색선을 **3V3**에 물려서 출력을 3.3V로 낮춘다.
대부분의 DC모터 홀 엔코더는 3.3~5V 동작이다. 사양이 5V 전용이면 A/B 각각에
저항 분압(예: 2kΩ + 3.3kΩ)이나 레벨시프터를 넣는다.

### 2. MDD10A 로직 레벨

MDD10A는 3.3V / 5V 로직을 모두 받는다. 별도 처리 없이 GPIO 직결.
**MDD10A GND와 ESP32 GND는 반드시 공통.**

### 3. 전원

- 모터 전원은 MDD10A의 배터리 단자로. ESP32에는 모터 전류가 흐르지 않게.
- ESP32 3V3에서 엔코더 4개(각 10~20mA) 정도는 문제없다.
- 1번 보드에서 CAN 두절이 반복된 이력이 있다. 모터 전원과 짐벌 24V가 같은 배터리면
  가감속 순간의 전압 처짐을 봐야 한다.

### 4. 2번 보드 Arduino IDE 설정

새 스케치 폴더마다 `Tools → USB CDC On Boot = Enabled`. 기본이 Disabled라 잊으면
시리얼이 안 뜬다.

## 1번 보드에 붙는 스텝모터 2개

| DRV8825 | 1번 보드 |
|---|---|
| STEP 1 / DIR 1 | **GPIO 15 / 16** |
| STEP 2 / DIR 2 | **GPIO 14 / 21** |
| ENABLE ×2 | GND (항상 켜짐) 또는 남는 핀 하나 공유 |
| RESET, SLEEP | 3V3 (필수) |

`step_control/drv8825_s3_test.ino` 의 STEP/DIR 5/4 는 CAN과 겹치므로 1번 보드에서는 위 핀으로 옮긴다.
1번 보드는 RTOS 라 STEP 펄스를 `delayMicroseconds` 루프로 만들면 100Hz 제어 태스크가 막힌다.
LEDC 나 RMT 로 내야 한다.

## 소프트웨어 (2번 보드)

- PWM: LEDC, 20kHz (MDD10A 상한), 4채널
- 엔코더: PCNT 4유닛, 쿼드러처 모드
- 주행 명령을 낼 때 UART 로 1번 보드에 `가속 시작 / 목표 가속도 / 램프 길이`를 보낸다
- 가감속 램프는 **0.7초 이상**으로 둔다. 짐벌 보상이 확실히 먹는 대역이 0.7Hz 아래다
