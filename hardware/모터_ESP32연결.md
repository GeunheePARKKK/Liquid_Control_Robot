# 모터 ESP32 연결 방법

**1. 모터에 원래 딸려온 케이블 확인**

한쪽 끝은 모터 보드에 이미 꽂혀있는 XT30(2+2) 커넥터, 반대쪽 끝은 피복 벗겨진 4가닥(빨강/검정/흰색/파랑)입니다.

- 빨강 = 전원 +
- 검정 = 전원 −
- 흰색 = CAN_H
- 파랑 = CAN_L

(흰색/파랑 중 어느 게 H인지 L인지는 반대로 연결해도 고장나지 않고 그냥 통신이 안 될 뿐이니, 안 되면 나중에 서로 바꿔보면 됩니다. 극성 있는 빨강/검정만 조심하면 돼요.)

**2. 전원 연결**

- 전원공급기 전압 24V로 맞추기 (허용범위 8~32V)
- 전류 제한 있으면 1~2A 정도로 낮게 설정
- 악어클립: 빨강 → 전원 +, 검정 → 전원 −
- 아직 전원 켜지 마세요, 배선 다 끝난 다음에 켤 겁니다

**3. CAN 트랜시버 배선**

- 모터 케이블의 흰색 → 트랜시버의 CANH
- 모터 케이블의 파랑 → 트랜시버의 CANL
- 트랜시버 VCC → ESP32-S3의 3V3 핀 (트랜시버가 3.3V 호환인 경우)
- 트랜시버 TXD → ESP32 아무 GPIO (예: GPIO4) — 나중에 코드에서 TWAI TX로 지정
- 트랜시버 RXD → ESP32 아무 GPIO (예: GPIO5) — 코드에서 TWAI RX로 지정

**4. 종단저항(100Ω) 연결**

트랜시버의 CANH-CANL 단자 사이에 그 100Ω 저항 다리를 양쪽에 걸쳐서 연결 (납땜하거나, 브레드보드 쓰면 그냥 꽂으면 됨)

**5. 그라운드 공통 연결 (제일 중요, 빼먹으면 안 됨)**

검정선(전원 −) ↔ 트랜시버 GND ↔ ESP32 GND, 이 세 군데를 전부 한 군데로 묶기

**6. 전원 켜기**

- 전원공급기 켜고 모터 보드 표시등 확인: 초록불(Enable) 켜지는지, 빨간불(Malfunction) 깜빡이지 않는지

- 이상 없으면 배선 완료
