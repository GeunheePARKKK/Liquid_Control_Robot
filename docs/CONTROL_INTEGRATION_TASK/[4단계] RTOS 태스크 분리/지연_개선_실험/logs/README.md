# 원본 로그

이 디렉터리의 `.txt` 파일은 `tools/capture.py`로 기록했고 `tools/check_tuning.py`로
분석했다. 파일 내용은 재현성을 위해 수정하지 않았다.

| 묶음 | 파일 | 목적 |
|---|---|---|
| ROLL Kd | `A_kpr2`, `B_kdr025`, `C_kdr040` | 바깥축 Kd 0.13→0.25→0.40 |
| 초기 분해 | `G_base`, `H_f030`, `I_f025` | raw 로그 추가 후 필터 지연 분리 |
| 기준 반복 | `baseline_01~03` | `ad0.20 f0.25 d2` 반복 편차 |
| CMD 필터 | `F030_01~02` | `f0.30`, 나머지 기준과 동일 |
| ACC 필터 | `AD025_01~02` | `ad0.25 f0.30` |
| CAN | `CAN100_01~02` | `ad0.20 f0.30 d1` |

일부 줄은 ESP32-S3 USB CDC 전송 중 바이트가 빠졌다. `check_tuning.py`는 가장 흔한
정상 필드 구성을 기준으로 손상된 줄을 제외하고, 펌웨어 `t`를 시간축으로 사용한다.
